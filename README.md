# Quality Control Machine

As part of my Year 1 tertiary studies, I had to develop a smart quality control solution using Arduino, PyCharm, AADFramework, and Arduino UNO. The project focused on detecting defects like dents in manufacturing products. Over three weeks, dedicating 3 hours weekly, I created a prototype that uses an IR sensor to detect irregularities in product shape and size, triggering a barrier to halt damaged products for manual removal.

As part of my year 1 tertiary studies, I had to propose an engineering project to apply some fundamentals of electronics and programming. I was tasked to utilise software like Arduino, Pycharm, AADFramework, and hardware like Arduino UNO. I defined an engineering manufacturing problem where defects like dents can occur due to irregularities in product production. My role is to utilise the above software and hardware and create a smart solution to provide simple quality control of products.

I was given 3 weeks before the submission date to complete this project. To complete this project, I dedicated 3 hours every week to work through this project. Some major goals that I set and achieved for this project include: program code creation, physical prototype building, and creation of PowerPoint slides defining overall project progress.

I created a prototype that detects product defects in terms of their shape and size. If there is a slight irregularity through IR sensor detection, a barrier will be erected, and the damaged product is halted while pending manual removal.
